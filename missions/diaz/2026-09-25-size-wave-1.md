# The first size wave: four nodes, nine shorter proofs

- **Mission** — Diaz's modulus conjecture, `3045e100-83a7-4863-9c02-21f90105f182`
- **Environment** — `0df444a` (Lean v4.33.1); mirrored on Mathlib v4.34.0
- **Date** — 2026-09-25

The size audit of 24 September ([the right size](2026-09-24-right-size.md))
found helpers that several proofs carried inline, and proofs that re-proved a
node already on the board. This is the first round of fixes: new nodes for the
shared helpers, and second proofs of the nodes that carried them.

## Four new nodes

| node | lines | taken from |
|---|---|---|
| `DiazModulus.exp_abs_transcendental_of_isAlgebraic_adjoin` | 57 | the four exponentials core of two proofs about `e^{\|λ\|}` |
| `DiazModulus.qbar_dependent_of_det_linear_forms` | 71 | a step shared by two proofs about six exponentials configurations |
| `Transcendence.circle_vanishing_ideal` | 98 | `candidate_vanishing_ideal` |
| `FourExp.dvd_of_small_values_at_scale` | 135 | `transcendence_criterion_continuous` |

Each is stated as generally as its proof allows. The first needs only that
`λ` and `λ̄` be algebraic over one ring `ℚ[x]`. Both proofs that carried it are
special cases: `x = λ`, and `x = iπ` with `λ = log 2 + iπ`. The circle node
works over any subfield `K` of `ℂ`; the candidate's case is `K = Q̄`.

Three of these fix restatements:
- `log_two_pi_dependent_forces_transcendence` re-proved
  `log_pair_square_ratio_transcendental`;
- `elliptic_torsion_excluded` restated `elliptic_axis_alignment`;
- `candidate_vanishing_ideal` re-proved both coordinate lemmas.

`hermite_lindemann_holds` carried its own copy of the Lindemann–Weierstrass
proof. It now imports the node. It could not import `Schanuel.hermite_lindemann`
or `Diaz.transcendental_of_candidate`, since both depend on it.

`transcendence_criterion_continuous` stays at 390 lines. The audit's sketch
found only one standalone piece in it, and that piece is now its own node.

## Checks before publishing

- On v4.33.1, the platform's version, all thirteen compile. `sorryAx` enters
  only through the stubs of imported nodes.
- Each proof states its node exactly as published.
- On v4.34, chained in one file against the mirror's real proofs, all thirteen
  use `propext`, `Classical.choice` and `Quot.sound` only. One proof needed a
  change there: a `rw [map_sub]` that v4.34 would not unify until given its
  function, `map_sub (ev x y)`. The change compiles on both versions.
- None of the four new statements was already on the board.

## On the board

The four statements published within a minute. The proofs went in two
waves:
1. the new nodes, plus the three second proofs that import only nodes already
   Proved;
2. once the new nodes read Proved, the six second proofs that import them.

All thirteen were ACCEPTED at the first attempt, with explanations attached and
read back.

## In the mirror

`carlok/diaz-modulus-lean` `b0cbcfd` counts 243 of 243:
- four new modules;
- seven modules regenerated from the new proofs;
- `Kernel.lean`, the hand-written backup of `candidate_vanishing_ideal`, now
  derives it from the circle node: 130 lines instead of 472.

`HermiteLindemann.lean` was already the short form.

Two tooling notes:
- The statement checker failed on `theorem Diaz.elliptic_torsion_excluded`,
  where the namespace is part of the name. That is how the platform stores
  the node. The checker now accepts it.
- The porter renames a helper whose name exists elsewhere in the library.
  Two new modules first got renamed helpers (`log_small`, `polar2`), because
  the old versions of their consumers still declared the same names. Once the
  consumers were regenerated, porting the two again made every module match
  its regeneration byte for byte.
